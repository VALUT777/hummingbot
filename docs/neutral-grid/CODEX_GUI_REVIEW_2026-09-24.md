# Приёмка GUI neutral-grid — 24 сентября 2026

## Одобренный дизайн

Локальный русскоязычный terminal показывает один согласованный зафиксированный снимок: цену, позицию, фактические незавершённые заявки, подтверждённые исполнения и сетку. Число ячеек берётся из сохранённой конфигурации `cell_count`; интерфейс не предполагает фиксированные 24 ячейки.

График строится на локально поставляемом TradingView Lightweight Charts 5.2.1. Вендор содержит Apache-2.0 `LICENSE`, `NOTICE` и provenance; на доступной пользователю странице нужна видимая атрибуция TradingView и ссылка. FreqUI был визуальным ориентиром для плотного операционного представления, его GPL-код не переносился. Legacy Hummingbot Dashboard отмечен поставщиком как неактивно поддерживаемый; Condor — только ориентир для статуса и наблюдаемости.

Свечи имеют явный источник: `Источник свечей: Robinhood Lighter, публичная история сделок` либо `Источник свечей: детерминированная офлайн-симуляция`; при недоступности показывается `Источник свечей: недоступен`. В attach-режиме публичные свечи разрешены только для согласованной идентичности и не заменяют состояние движка. Все цены, объёмы и идентификаторы остаются точными строками. Время исполнения выводится через `ru-RU` из секунд эпохи; таблица явно помечает колонки `Время`, `Сторона`, `Роль / ячейка`.

Линии графика показывают границы сетки и только фактические незавершённые заявки из выбранного committed snapshot. TP не синтезируются из предполагаемой будущей цены: `TP` появляется лишь как фактическая строка заявки. Для частичного входа при 2 исполнениях по 3 LIT принятый сценарий показывает противоположный TP объёмом 6 LIT.

## Сохранённые границы

Изменений в engine, конфигурации, схеме SQLite и миграциях нет. Терминал читает committed snapshot; заявки идут только через существующую durable queue. Материальная привязка Start к конфигурации и market rules, fail-closed при stale/неполных данных, revision/idempotency, подтверждения Pause/Stop/manual settlement и loopback-only sidecar сохраняются.
